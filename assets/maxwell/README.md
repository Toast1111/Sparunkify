# Maxwell assets

- `source/maxwell.fbx`: the original model supplied for this project, renamed for clarity.
- `mesh.js`: browser mesh generated with `python scripts/convert-maxwell.py`.
- `dingus_nowhiskers.jpg`: body texture.
- `dingus_whiskers.tga.png`: transparent whisker texture.

The runtime textures are also the canonical source textures. The model source and this document are excluded from the extension ZIP.
